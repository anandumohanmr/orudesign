# Christy & Shereena — Kerala Wedding Story

A responsive, animated, storybook-style wedding invitation built with HTML, CSS and vanilla JavaScript.

## Run locally

1. Extract the ZIP archive.
2. Open the `christy_site` folder in VS Code.
3. Start a local server (VS Code Live Server is recommended), then open `index.html`.

A local server is recommended so all images and assets load consistently.

## Included

- Kerala/Kochi-inspired backwater hero, coconut palms and Chinese fishing-net details.
- Scroll-reveal and gentle parallax effects, plus falling flower petals.
- Separate engagement ring-exchange and church-wedding character illustrations.
- Original couple photography gallery with lightbox.
- Betrothal and wedding information, plus a live IST countdown.
- Google Maps search links for the two churches.
- Original, locally included romantic ambient instrumental MP3. The MP3 is included inside the ZIP at `assets/audio/kerala-wedding-ambient.mp3`. The website attempts audible autoplay immediately on entry. If the browser blocks sound-on-load autoplay, a visible prompt appears and the first tap/click/key press anywhere on the page starts music automatically; visitors do not need to find or click the music button. The music toggle can pause/resume it. Browser policies do not allow any website to guarantee audible autoplay before user interaction.
- Responsive mobile and desktop layouts, including reduced-motion support.

The two church links use Google Maps search URLs rather than unverified coordinates. Replace them with exact venue pins if the families provide the preferred map locations.


## Music playback

The music track is included at `assets/audio/kerala-wedding-ambient.mp3` (40 seconds, looping). Audible autoplay is attempted immediately on page entry. If Chrome, Safari or another browser blocks it, a clear “Tap anywhere once to start the wedding music” prompt appears; the first tap, click or key press anywhere starts playback automatically. This browser restriction cannot be bypassed by website code.
