ABHISHEK & ANJANA — CINEMATIC WEDDING WEBSITE
================================================

OPEN
- Extract this ZIP.
- Open wedding-site/index.html in Chrome, Edge, Safari or Firefox.
- No local server is required. The website is built with HTML, CSS and JavaScript.
- An internet connection is used for Google Fonts and Bootstrap CDN styling/icons.

ADD YOUR WEDDING SONG
- Open wedding-site/audio/
- Copy your MP3 song into this folder and rename it to: song.mp3
- The website will use audio/song.mp3 automatically.
- Or use the folder/music button on the website to select any audio file from your device.
- Browsers block sound autoplay until a visitor interacts with the page. Music begins after the visitor taps
  “Tap to open the temple door”. This is a browser restriction, not a website issue.

CUSTOMISE
- Edit wedding-site/js/config.js to change the song filename, volume, wedding date, rain and leaf settings.
- Replace images/photo1.jpg through photo6.jpg to update the couple photographs.
- Keep the same filenames if you replace the photos.
- Photos retain their natural aspect ratio; they are not stretched or forcibly cropped.
- The wedding invitation scan is not included in the website gallery.
