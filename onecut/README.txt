ONECUT WEBSITE — ORU DESIGN

Files:
- index.html       Main responsive website
- styles.css       Futuristic visual theme, responsive layout and motion
- script.js        Mobile menu, reveal animations, UPI copy and parallax
- assets/          OneCut logo, Oru Design logo and supplied UPI QR
- serve.py         Optional local preview server (Python 3)

PREVIEW:
1. Double-click index.html to open it in a browser, OR
2. Open PowerShell in this folder and run:
   python serve.py
3. Visit http://localhost:8000

PUBLISH:
Upload the complete folder contents to your web host (for example, the public_html folder).
Keep the assets folder next to index.html.

DOWNLOADS:
Windows button points to the MEGA URL supplied by the owner.
macOS and Android are displayed as Coming Soon because no verified download links were supplied.
Replace these buttons in index.html once real installers/APK files are ready.
